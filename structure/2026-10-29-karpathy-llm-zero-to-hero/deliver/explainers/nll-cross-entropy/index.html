NLL / 交叉熵
到底在罚什么？

把模型当成一个考生：交卷前，它会给每个候选答案打一个把握。 NLL 就是交卷后按这个把握收的罚款——把握越小、还越嘴硬，罚得越狠。

token ID→ embedding→ 模型→ logits→ softmax→ 概率→ NLL

三十秒版

  1. 模型只干一件事：给 27 个候选字符各一个“把握”，加起来 100%。
  2. 真实答案出现，只看它拿到的那一份 p，别的全不管。
  3. 罚款 = −ln p。把握 100% 罚 0；10% 罚 2.3；1% 罚 4.6。
  4. 一整批题的罚款取平均，就是 loss，也就是 NLL / 交叉熵。

只需要记住一个字：“砍半，加 0.69”——把握每减半，罚款加一格。

02罚款表：把握越低，罚得越陡

横轴是模型给真实答案的把握，纵轴是这一题的罚款 −ln p。 手指从右往左走：越靠近 0，曲线越陡，罚款涨得越快。

03为什么非得是 log？

因为对数有一个非常朴素的性格：按倍率算账，不按差值算账。而这正好是“把握”该有的算法。

  1. 砍一半，加 0.69——不管你现在在哪

    100% → 50%，罚 +0.69；50% → 25%，还是 +0.69；1% → 0.5%，依然是 +0.69。信心减半，代价相同。换成 log₂，这一格正好是 1 bit。

  2. 把握越接近 0，罚得越没有上限

    你说“这事绝对不可能”，结果它真发生了——罚款趋于无穷。所以模型很快学会“别把话说死”。代码里要先加一点平滑，否则 −ln 0 会直接变无穷。

  3. 换成 1−p 就彻底失效了

    1−p 最多罚到 1，而且 p=1% 和 p=0.1% 只差 0.009 分，模型分不清“很不可能”和“绝不可能”。log 把这段差距拉成 2.3 分，专治嘴硬。

一句话：1−p 罚的是“你错了多少”；−ln p 罚的是“你错得有多自信”。后者才是我们想让模型改的东西。

04换个说法：这是一场打赌

你押“明天会不会下雨”。结果一样，但你说的把握不同，丢的面子完全不同。

你押了 90%，真下了。
你说得基本准，只丢一点点面子。

你押了 10%，结果也下了。
不是错得更离谱，是错得特别自信。

注意罚的不是“错”：两次都猜错了，但第一次留了余地，第二次把话说死了。NLL 罚的是后者——它逼模型在没把握的时候，把概率摊开。

05NLL 就是这份“平均罚款”

三个字母拆开看，一点也不神秘。

字母英文人话
NNegative似然越大越好，加个负号就变成“越小越好”，符合 loss 的习惯
LLog把“把握”换算成罚款刻度，1% 和 0.1% 才拉得开
LLikelihood似然 = 模型给“真实发生的那件事”的把握

单张卷子的罚款是 −ln p；一整批卷子取平均，就是训练时盯着看的那个数。

06那“交叉熵”跟 NLL 差在哪？

差的不是算法，是说话的角度。答案唯一的时候，它们是同一个数。

名字字面意思什么时候等于谁
NLL 负的对数似然：−ln（给真答案的把握） 答案只有一个时的单题罚款
交叉熵 拿“真实分布 p”和“模型分布 q”对照：−Σ pᵢ ln qᵢ p 是 one-hot（只有真答案占 100%）时，正好等于 NLL
loss 一个 batch 上这些罚款的平均 训练日志里打印的那个数

“交叉”两个字，来自拿两套分布对着比：真实的 p，模型的 q。 语言模型的真实答案每次只有一个字符，所以 p 长这样：

软标签的情况：如果真实答案是“70% 是 A、30% 是 B”，交叉熵就是 −(0.7 ln qA + 0.3 ln qB)。这是 NLL 的自然推广，知识蒸馏训练学生模型时会用到。

07它跟训练的关系：只有一句话

训练就是调参数，让这堆罚款的平均值变小。没有别的。

  1. 27 个字符闭眼瞎猜，每题罚 ln 27 = 3.30。这是“什么都不学”的基准线。
  2. 手册里的 bigram 从 3.30 练到 2.45，说明它学到了“e 后面大概率不是 x”这类接法。
  3. 但 2.45 不是“2.45% 正确率”，它只是“平均有多意外”。

所以看 loss 要横向比：跟瞎猜比、跟上一版比、跟验证集比。

常见误会：loss 不是准确率。
全蒙对，准确率 100%，但只要你每题都只给 40% 的把握，交叉熵照样很高。
反过来，loss 降到 0 需要每题都给 100%——真实语料上不可能发生，也不该追求。

08三个最容易记错的点

  • ✕
    “交叉熵就是准确率”
    不是。准确率只看对错，交叉熵看把握。全对但全靠蒙，准确率满分，交叉熵一样很难看。
  • ✕
    “loss 越低，模型就一定越好”
    只在同一份数据、同一套分词器上比才有意义。换数据集、换 tokenizer，loss 的绝对值就不可比了。
  • ✕
    “NLL 和交叉熵是两个东西”
    答案唯一时是同一个数，只是一个从“似然”起名，一个从“两个分布的距离”起名。
