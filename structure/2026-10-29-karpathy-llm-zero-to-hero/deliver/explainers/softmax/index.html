softmax：
分数怎么变成把握

模型最后一层吐出一排分数，softmax 负责把它们变成加起来正好 100% 的把握。 只有两步：先 exp，再除以总和。这篇是把这四格漫画拆开，配着数字讲一遍。

三十秒版

  1. 输入是一排分数，可正可负，加起来是多少都行。
  2. 每个分数取 e 的次方：全部变正，大的被放大，小的被压扁。
  3. 再除以它们的和：变成份额，加起来正好 100%。
  4. 排序一位都不会变；分数差 1，概率大约差 2.72 倍。

一句话：softmax 不改排名，只改刻度——把“谁更像”换成“占几成”。

用的就是上一篇那组候选（m / e / a / s / x / 其他），数字全程可对上。 为了画得下，只画前 5 个，剩下 22 个字符合起来叫“其他”。

四步：分数 → exp → 求和 → 相除。第三步的“求和”只是为了第四步做分母，它本身没有含义。

念出来就是“第 i 个的 e 次方，除以所有 e 次方的和”。分子分母都只跟分数有关，没有别的魔法。

03为什么非得先 exp？

三个条件筛下来，exp 几乎是唯一顺手的选择。想清楚这三条，面试就不怕被追问。

  1. 必须全变正数，才能当“份额”

    分数里有 −0.2、−1.3，直接除以总和会出现负概率。ez 恒大于 0，这一步把符号问题一次解决。

  2. 必须单调，才不改变排名

    ez 随 z 一直往上走，所以 softmax 之后谁大谁小的顺序和 logits 完全一致。它只换刻度，不换结论。

  3. 把“差值”变成“倍数”，正好配得上 log

    z 差 1，概率就相差 e ≈ 2.72 倍；差 2，约 7.4 倍。所以 logits 本质是对数赔率，softmax 负责把它还原成份额。

分数差概率倍数例子（同一组里）
0.72×71% vs 35%
1.02.72×71% vs 26%
1.64.95×71% vs 14%
2.310×71% vs 7%

反例：把分数直接除以总和？负数会变负概率。
取 max 再归一化？变成“不是 0 就是 1”，没有梯度，没法训练。
exp 同时满足：恒正、单调、光滑可导——最后一条是关键，因为后面要拿它跟交叉熵一起求梯度。

04新同事最常踩的三个坑

这三条在 code review 里出现频率极高，先背下来能省很多来回。

  • ✕
    直接 exp，不小心里面有个 1000
    e1000 直接溢出成 inf，除完就是 nan。标准写法是先减最大值：softmax(z) = softmax(z − max z)，数学上完全等价，因为分子分母同乘了 e−max。框架里的 F.softmax 已经做了，自己写 numpy 版时要记得。
  • ✕
    把输出当成“模型的信心”
    它只是相对份额。所有 logits 同时加 10，概率一点不变——所以“模型 90% 确定”这种说法要看校准，不能直接当事实读。
  • ✕
    多标签任务用了 softmax
    softmax 假设候选互斥（只有一个正确答案）。如果一张图可能同时是“猫”和“沙发”，每个标签应该独立过 sigmoid，而不是互相抢份额。
被问到时的一句话回答：“先减 max 防溢出，再 exp 变正并放大差距，最后除以和归一化；输出和为 1，排序与 logits 一致，梯度是 p − y。”

06代码里长什么样

手写一遍比读十遍有用。注意第二行那个“减最大值”，以及最后一行框架内部做了什么。

import numpy as np

def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)   # 防溢出：整体平移，结果不变
    e = np.exp(z)                            # 全部变正，且放大差距
    return e / e.sum(axis=-1, keepdims=True)  # 归一化：加起来 1
import torch
import torch.nn.functional as F

p = F.softmax(logits, dim=-1)              # 每行各自归一化
loss = F.cross_entropy(logits, target)     # 内部用 log_softmax，比先 softmax 再取 log 稳

记住 dim=-1：它决定“在哪一维上凑成 100%”。批次里每一行是独立的一道题，所以是最后一维，不是整个张量。

07两个近亲：sigmoid 和温度

日常读代码时，这两个词一定会撞上，顺手一起认了。

sigmoid 是 2 类的 softmax。把 softmax 用在两个候选上，其中一个固定为 0 分， 结果就是 1 / (1 + e−x)。所以二分类用 sigmoid、多分类用 softmax，是同一件事的两种写法。
