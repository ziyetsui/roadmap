从数学表达式到自然语言

这份对照把教学代码里的每个核心运算和实验，写成“数学表达式 → 自然语言表达式”。公式下方附中文读法，方便开口讲解。这里的箭头表示解释对应关系，不表示代码逐字等于数学公式。

一、一个数字，也记录它怎样影响结果

数学表达式自然语言表达式
v = (data, grad, parents, op)读作：维等于 data、grad、parents、op 组成的记录Value把一个数装进记录卡：当前数值、结果变化时它要承担的影响、它从哪些上游数算来，以及用了什么运算。
v.grad = 0读作：维的梯度初始为零一开始还没有从最终结果传回任何影响，所以先把这张记录卡收到的影响设为零。
v._backward = 空操作读作：维的反向规则暂时什么也不做如果这个数是最终结果，或没有上游运算需要处理，默认就不再向前传。

二、每种运算都有一条反向规则

数学表达式自然语言表达式
z = x + y
∂z/∂x = 1，∂z/∂y = 1读作：z 等于 x 加 y；z 对 x 和 y 的偏导数都等于一		加法结果多一份，任一输入多一份都会让结果多一份。因此，下游传回多少影响，x 和 y 就各自收到多少。
x.grad += z.grad
y.grad += z.grad读作：x 和 y 的梯度，各自加上 z 收到的梯度		把结果的影响原样分给两个加数；用“累加”是为了保留这个数从其他路径收到的影响。
z = x × y
∂z/∂x = y，∂z/∂y = x读作：z 等于 x 乘 y；z 对 x 的偏导数是 y，对 y 的偏导数是 x		看 x 的影响时，把 y 固定住，x 的变化会被 y 倍放大；看 y 时则固定 x，所以被 x 倍放大。
x.grad += y × z.grad
y.grad += x × z.grad读作：x 收到 y 乘以 z 的梯度；y 收到 x 乘以 z 的梯度		先看这一站的放大倍数，再乘上结果从下游收到的影响。这就是把局部导数接到整条计算链上。
z = xⁿ
∂z/∂x = n × xⁿ⁻¹读作：z 等于 x 的 n 次方；z 对 x 的导数等于 n 乘 x 的 n 减一次方		幂函数有固定的斜率规则。代码把这个局部斜率乘以下游传来的影响，再加到 x 的梯度上。
若 n = 0，则 ∂(x⁰)/∂x = 0读作：指数是零时，x 的零次方对 x 的导数是零零次方是常数 1，不随 x 改变，所以没有影响传回 x。代码因此在指数不为零时才执行幂函数的导数计算。
t = tanh(x)
∂t/∂x = 1 − t²读作：t 等于双曲正切 x；导数等于一减 t 的平方		tanh 把输入压到 -1 到 1。代码先算出输出 t，再用输出算出这一站的局部斜率，把影响传回输入。
−x = x × (−1)
x − y = x + (−y)
x / y = x × y⁻¹读作：负 x 等于 x 乘负一；减法改写为加负数；除法改写为乘倒数		负号、减法和除法不另造一套反向规则，而是改写成已会处理的乘法、加法和乘方。

三、从最终结果往回传影响

数学表达式自然语言表达式
∂L/∂L = 1读作：L 对自身的导数等于一从最终结果开始回传时，先给它自己的影响标为 1，表示结果对自身变化一比一。
parents → node → order
反向遍历 order读作：先沿父节点排好顺序，再按相反顺序处理		先找齐结果依赖过的所有数字，并排成计算顺序；之后从结果往输入方向走。每个节点只处理一次，但同一输入收到的多条贡献仍然相加。
若 q = a + a，则 ∂q/∂a = 2
若 q = a × a，则 ∂q/∂a = 2a读作：a 加 a 对 a 的导数是二；a 乘 a 对 a 的导数是二 a		同一个数字用了两次，就有两条回传路线。两条路线的影响要汇总，不能让后一条覆盖前一条。
∂L/∂x = (∂L/∂z) × (∂z/∂x)读作：L 对 x 的导数，等于 L 对 z 的导数乘以 z 对 x 的导数沿一条计算链走时，把每一站的局部放大倍数相乘。若有多条不同路线通向同一个输入，再把各路线的贡献加起来。

四、五个小实验分别在验证什么

数学表达式自然语言表达式
f(x) = 3x² − 4x + 5
[f(2+h) − f(2)] / h → 8读作：三 x 平方减四 x 加五；用函数值的变化除以 x 的变化，逼近八		实验 1：有限差分把 x 从 2 往前挪一点，观察 f 增加多少。再用输出变化除以输入变化，估计这一点附近的斜率。h 越小通常越准，但过小会受浮点舍入影响。
d = 2 × 3 + 4 = 10
∂d/∂a = 3，∂d/∂b = 2，∂d/∂c = 1读作：d 等于二乘三加四，结果十；三个输入的影响依次是三、二、一		实验 2：计算图用一个乘法接一个加法。分别固定另外两个输入，只改变一个输入，检查手写规则能否得到预期的影响。
a = 3
∂(a+a)/∂a = 2
∂(a×a)/∂a = 6读作：a 等于三；a 加 a 的导数是二；a 乘 a 的导数是六		实验 3：重复节点同一个 a 在表达式里出现两次，程序要把两条路线的贡献累加。乘法例子中，a=3，因此导数为 3+3=6。
loss = (2w − 4)²
w ← w − 0.1 × ∂loss/∂w读作：损失等于二 w 减四的平方；w 减去零点一乘损失对 w 的导数		实验 4：一次更新先看当前参数造成多大误差，再沿着让误差下降的方向挪动参数。学习率 0.1 是这次示范的步幅；更新后重新计算误差。
loss = ¼ × Σᵢ(predᵢ − targetᵢ)²
p ← p − 0.05 × ∂loss/∂p读作：损失是四个样本平方误差的平均；参数减去零点零五乘损失对参数的导数		实验 5：四样本训练网络分别预测四个输入，把预测与目标的差异合成平均误差。然后将误差的影响传回所有权重和偏置，并各自小幅调整。重复 200 轮，观察重新计算的误差和预测。

五、网络结构与训练流程

数学表达式自然语言表达式
neuron(x) = tanh(Σᵢ wᵢxᵢ + b)读作：神经元输出等于双曲正切，括号里是每个输入乘权重后求和再加偏置一个神经元给每个输入分配权重，把加权结果加起来，加上可调偏置，再通过 tanh 得到输出。
Σᵢ wᵢxᵢ + b
从 b 开始累加各个 wᵢxᵢ读作：从偏置开始，把每个输入与对应权重的乘积逐个加上		代码用 `sum(..., b)` 做加权求和，并指定从偏置开始。`zip(weights, inputs)` 让每个权重和对应输入配成一对。
layer(x) = [neuron₁(x), …, neuronₘ(x)]读作：一层的输出是多个神经元各自的输出一层包含多个并排的神经元；它们读取同一份输入，各自给出一个结果。
MLP(x) = layerₖ(…layer₂(layer₁(x)))读作：多层感知器把输入依次送过每一层把多层接起来：前一层输出交给后一层处理。最后一层给出预测。
MLP(3, [4, 4, 1])读作：三维输入，后面依次是四个、四个、一个神经元这个示例接收三个输入值，经过宽度为 4、4、1 的三层网络。最后只有一个输出，所以返回单个预测值；若最后一层有多个神经元，就返回一组输出。
sizes = [input_count] + widths
相邻层大小依次配对读作：把输入宽度和各层宽度排成一列，再连接相邻两层		代码根据相邻两层的神经元数量创建层，并把每一层的权重和偏置收集起来，供训练使用。
每轮：loss → 清梯度 → backward → 更新参数 → 重算 loss读作：先算损失、清空旧梯度、反向求导、更新参数，再重新计算损失每轮都用当前参数重新做一次预测；清掉上轮留下的梯度；从误差反向计算影响；按影响调整参数。调整后必须重新预测，才能知道新误差。
每 50 轮打印一次；共更新 200 轮读作：一共训练两百次，每五十次汇报一次程序在第 50、100、150、200 次更新后重新计算并打印误差，便于观察训练过程。打印时用的是更新后的新计算结果。
random.seed(42)读作：随机种子设为四十二固定随机数的起点，让初始化和实验更容易重复。它不会保证模型效果更好，也不能保证所有设备上的计算完全一致。
parameters = weights ∪ biases读作：模型参数由权重和偏置组成把所有需要学习的权重和偏置集中起来，统一清梯度、读取梯度和更新。

阅读边界：数学表达式用于说明代码中的核心计算，不是把每一行 Python 语法硬译成公式。四条样本和 200 次更新只是小型演示，不能据此判断网络对新数据的泛化能力。
