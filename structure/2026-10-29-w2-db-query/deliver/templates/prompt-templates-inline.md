# 就地提示词模板汇总

助手抽象模板；替换〔〕后使用。完整原文与边界以手册对应位置为准。

## 可套用模板｜DB-V01

```text
为〔目标前端项目〕生成参照〔设计参考〕的设计规则，保存到〔规则文件路径〕。
明确颜色、字体、边框、间距、布局与交互状态的可检查要求，并用〔适用页面/组件〕说明规则范围。
```

## 可套用模板｜DB-V02

```text
深度阅读〔参考网站或已提供页面材料〕的页面结构与样式，抽取静态及交互细节的design token，更新〔风格文件路径〕。
覆盖颜色、字体、边框、间距、布局与状态；记录依据和未能核验的部分，不凭印象补全。
```


## 可套用模板｜W2-P02

```text

解析所有SQL，仅接受〔允许语句类型〕；无〔限制子句〕时补〔默认上限〕，返回JSON供前端表格展示，错误需明确。
后端采用〔技术栈〕，前端采用〔技术栈〕，编辑器使用〔组件〕；模型凭据从〔环境变量名〕读取。
定义〔路由前缀〕下的连接列表、添加连接、读取元数据、执行查询、自然语言生成接口，逐项给请求/响应与失败格式；跨域允许范围为〔实际范围〕。
先确认认证、数据存储、只读权限和结果上限，输出需求、契约、计划及验收，不将历史演示连接串当真实配置。
```

## 可套用模板｜RUNTIME

```text
系统消息：你是〔目标数据库方言〕的SQL生成器。
数据库结构：〔实际表/视图、schema、列类型、主键、非空及唯一约束〕。
仅生成SELECT，不输出写入或DDL；始终添加LIMIT，最多〔结果上限〕行。
按〔目标方言〕使用〔标识符引用规则、schema限定及LIMIT语法〕；理解〔输入语言范围〕。
只返回SQL正文，不输出解释、Markdown或额外文字。
用户消息：〔自然语言业务查询，含筛选、结果粒度及排序〕。
消息构造保留system/user分离；生成后仍经〔解析与人工审核流程〕，不把提示词约束当作数据库权限。
```
